# Mengo-Hub Admin Guide

This guide covers admin operations: certificates, audit logs, feature toggles, and security.

Admin endpoints:
- POST /api/admin/certificate/generate
- POST /api/admin/feature/toggle
- GET  /api/admin/audit-logs
- GET  /api/admin/security/stats

Keep SUPER_ADMIN_API_TOKEN and ADMIN_ID secure. Rotate certificates regularly.
