## 📞 Quick Reference

### Start the system:
```bash
python flask_app.py
# Server runs on http://localhost:5000
```

### Database:
```bash
# PostgreSQL connection string in .env
DATABASE_URL=postgresql://user:pass@localhost:5432/mengo_hub
```

### API Examples:
```bash
# Get student dashboard
curl http://localhost:5000/api/dashboard/student

# Upload document
curl -X POST http://localhost:5000/api/documents/upload \
  -F "file=@document.pdf"

# Scan document with OCR
curl -X POST http://localhost:5000/api/media/scan/ocr \
  -F "file=@scan.jpg"
```
